# AIELTS

IELTS band шкаласы бойынша сөйлеу мен жазуды бағалайтын AI құралы — тіл үйренушілерге, презентация дайындаушыларға және IELTS/TOEFL тапсырушыларға арналған.

## Мүмкіндіктер

- **Дауыс → мәтін.** Браузердің Web Speech API-і арқылы, ағылшын тілінде (API кілт керек емес). Chrome/Edge-те жақсы жұмыс істейді.
- **Өз жазбаңызды тыңдау.** Сөйлеген кезде дыбыс та жазылады — транскриптпен қатар өзіңізді тыңдай аласыз. Жазба ешқайда жіберілмейді, тек беттің жадында тұрады.
- **Сөйлеу көрсеткіштері.** Қарқын (сөз/мин), артық сөздер, қайталаулар, ұзақ кідірістер — браузерде есептеліп, бағалауға қосылады.
- **Үлгі нәтиже.** Кілтсіз, тіркелусіз, бірінші секундта нағыз нәтиже қалай көрінетінін көруге болады.
- **Тапсырмалар банкі.** Дайын IELTS Writing/Speaking тапсырмалары + емтихан таймері. Өз тапсырмаңызды да жазуға болады.
- **IELTS band бағасы.** 0–9, жарты балл қадаммен, ресми критерийлер бойынша (Task Achievement / Response, Coherence немесе Fluency, Lexical Resource, Grammatical Range).
- **Мәтін ішіндегі түзетулер.** Қателер түпнұсқа мәтінде белгіленіп, төмендегі тізіммен нөмірленеді.
- **Тарих және прогресс.** Әр талпыныс `localStorage`-та сақталады, балл динамикасы графикпен көрсетіледі, алдыңғы талпыныспен айырма (+0.5 / −0.5) шығады.
- **PDF / басып шығару.** Нәтиже панелін мұғалімге жіберуге болады.
- **Екі тіл.** Интерфейс те, кері байланыс та қазақ және ағылшын тілдерінде. ҚАЗ/ENG қосқышы екеуін бірден ауыстырады — API жауабы екі тілде де келетіндіктен, тіл ауыстырғанда қайта сұраныс жіберілмейді.

## Іске қосу

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY кілтін қойыңыз
npm run dev
```

`npm run dev` кезінде `api/analyze.js` Vite dev-серверіне қосылады (`vite.config.js` ішіндегі `serverlessApi` плагині), сондықтан локалда да, Vercel-де де бір код орындалады.

## Vercel-ге деплой

```bash
vercel
```

Vercel панелінде `ANTHROPIC_API_KEY` environment variable-ін қосыңыз. `api/` қалтасы автоматты түрде serverless функция ретінде танылады.

Қосымша (міндетті емес): `RATE_LIMIT_PER_HOUR` — бір IP-ден сағатына рұқсат етілген талдау саны (әдепкі 10).

## Деректер қайда сақталады

| | Кірмеген (қонақ) | Google арқылы кірген |
|---|---|---|
| Тарих | браузердің `localStorage`-ы | Supabase (Postgres) |
| Басқа құрылғыда көріне ме | жоқ | иә |
| Браузер тазаласа | жоғалады | сақталады |
| Шектеу | соңғы 40 талпыныс | соңғы 200 талпыныс |

Кіру **міндетті емес** — сайт тіркелусіз де толық жұмыс істейді. Қонақ ретінде жиналған тарих алғаш кірген кезде автоматты түрде аккаунтқа көшіріледі, сосын localStorage тазаланады (сол себепті екі рет жүктелмейді).

Талданатын мәтін өзі ешқашан бөлек сақталмайды — тек талпыныс жазбасының ішінде. Кірмеген жағдайда ол браузерден шықпайды.

## Supabase баптау (міндетті емес)

Аккаунтсыз жұмыс істегіңіз келсе, бұл бөлімді өткізіп жіберіңіз — `VITE_SUPABASE_*` айнымалылары болмаса, кіру батырмасы мүлдем көрінбейді.

1. [supabase.com](https://supabase.com) → жаңа жоба ашыңыз.
2. **SQL Editor** → [`supabase/schema.sql`](supabase/schema.sql) ішіндегі кодты қойып, **Run**. Бұл `attempts` кестесін және Row Level Security ережелерін жасайды.
3. **Authentication → Providers → Google** → қосыңыз. Google Cloud Console-да OAuth client құрып, Client ID мен Secret-ті қойыңыз. Google жағындағы redirect URI:
   `https://<жоба>.supabase.co/auth/v1/callback`
4. **Authentication → URL Configuration** → Site URL ретінде Vercel мекенжайыңызды, ал Redirect URLs тізіміне `http://localhost:5173` қосыңыз (локалда кіру үшін).
5. **Settings → API** → Project URL мен `anon` кілтті `.env.local` файлына (және Vercel env-іне) қойыңыз.

`anon` кілт — ашық кілт, оны браузерге беру қалыпты жағдай. Қауіпсіздікті RLS қамтамасыз етеді: әр SQL сұранысы `auth.uid()` арқылы шектеледі, сондықтан бір қолданушы екіншісінің деректерін оқи да, өшіре де алмайды.

## Ескертулер мен шектеулер

- **Дауыс тану браузерге тәуелді.** Chrome/Edge — жақсы, Firefox — қолдамайды. Қолдамаған жағдайда UI «Жазу» режимін ұсынады. Кейін Whisper API-ге көшкіңіз келсе, тек `useSpeechRecognition` хугі мен жаңа serverless endpoint қажет — қалған UI өзгермейді.
- **Айтылым бағаланбайды.** Құрал транскриптпен жұмыс істейді, дыбыспен емес — сондықтан IELTS Speaking-тің Pronunciation критерийі жоқ.
- **Сөйлеу көрсеткіштері шамамен.** Chrome «um», «uh» сияқты дыбыстарды көбіне мәтінге қоспайды, ал кідірістер тану кідірісіне байланысты дәл емес. Модельге де солай деп айтылған.
- **Rate limit жадта сақталады.** Serverless инстанстар уақытша әрі бірнешеу болуы мүмкін, сондықтан бұл кездейсоқ артық жүктемеден ғана қорғайды. Жария деплой үшін ортақ қойма керек (Vercel KV, Upstash).
- **Дыбыс жазбасы сақталмайды.** Тек беттің жадында тұрады: серверге де, localStorage-қа да, Supabase-ке де жіберілмейді, бетті жаңартсаңыз жоғалады. Бұл әдейі — аудио файлдар үлкен әрі құпиялылық тұрғысынан жауапкершілік артады.
- **Кірмеген қолданушының тарихы тек осы браузерде.** Кірген соң Supabase-ке көшеді (жоғарыдағы кестені қараңыз).
- **Талпыныстар өзгертілмейді.** `attempts` кестесінде `update` политикасы әдейі жоқ — жазба тек қосылады және өшіріледі.
- **«Сөйлеу» мен «Жазу» режимдерінің мәтіндері бөлек** сақталады — қосқышты ауыстырғанда бір-біріне араласпайды.
- **API кілт браузерге түспейді** — тек serverless функцияда қолданылады.
- **Жаңа тіл қосу:** `src/i18n.jsx` ішіндегі `translations` объектісіне және `api/analyze.js` ішіндегі `bilingual()` схемасына кілт қосу жеткілікті.
